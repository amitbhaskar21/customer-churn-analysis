# Customer Churn Analysis and Prediction

## Project Overview
This project analyzes customer churn using the Telco Customer Churn Dataset. The project focuses on understanding customer churn patterns and predicting whether a customer is likely to churn.

## Objectives
- Clean and preprocess the customer data
- Analyze customer churn patterns
- Identify factors related to customer churn
- Build a machine learning model
- Predict customer churn

## Dataset
**Telco Customer Churn Dataset**

- Original records: 7,043
- Attributes: 21
- Final records after preprocessing: 7,032
- Target variable: Churn

## Exploratory Data Analysis
The project analyzes churn based on:
- Contract Type
- Tenure
- Monthly Charges
- Internet Service

## Machine Learning
**Model Used:** Logistic Regression

**Model Accuracy:** 78.54%

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Key Findings
- Month-to-month customers had a higher churn rate.
- Customers with higher monthly charges showed higher churn.
- Customers with shorter tenure showed higher churn.
- Fiber optic customers showed a higher churn rate compared with other internet-service groups.
